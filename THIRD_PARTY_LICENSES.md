## Latin Modern fonts

The package includes Latin Modern Roman, Sans, Mono, and Math web fonts. The
math font is based on Latin Modern Math 1.959 by Bogusław Jackowski, Piotr
Strzelczyk, and Piotr Pianowski on behalf of TeX user groups. It is distributed
under the GUST Font License, an instance of the LaTeX Project Public License
1.3c or later.

The modified math font is presented as `Latin Modern Math Upright` to distinguish
it from the original font.

The GUST Font License text supplied with Latin Modern Math follows:
